# Chunking Rules

## Purpose
Define how documents and records are chunked for retrieval.

## Chunking Principles
- Chunk by semantic unit
- Preserve headings and section boundaries
- Keep ADRs atomic where possible
- Keep tables associated with surrounding explanation

## Chunk Types
- Business capability
- Use case
- Service/module
- API contract
- ADR
- Runbook step
- Incident summary
- Data entity
- Policy / control
