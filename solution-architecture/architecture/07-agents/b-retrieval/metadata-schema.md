# Metadata Schema

## Purpose
Define the metadata fields used to classify and retrieve agent context.

## Required Metadata Fields
- title
- section
- project
- domain
- document_type
- owner
- status
- confidentiality
- source_of_truth
- last_reviewed
- tags

## Optional Metadata Fields
- environment
- site
- system
- capability
- agent_relevance
- freshness_class
