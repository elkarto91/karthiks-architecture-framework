# Architecture Decisions (ADR)

## Purpose
This section captures all significant architectural decisions made for the system.

These decisions provide:
- traceability
- reasoning context
- historical record
- input for AI-assisted reasoning

## Structure

- Each ADR is a separate file
- Files follow naming: `adr-XXXX-title.md`
- Status must be maintained

## Lifecycle
- Proposed → Accepted → Deprecated → Superseded

## Guidelines
- Do not edit accepted ADRs directly
- Create new ADRs for changes
- Link related ADRs
