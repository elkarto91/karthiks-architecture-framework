# ADR Template Guide

## 1. Purpose
Captures an important architectural decision, its context, alternatives, and consequences.

This is the primary mechanism for preserving architectural intent over time.

---

## 2. Template

# ADR-XXXX: <Short Title>

## Status
Proposed | Accepted | Rejected | Deprecated | Superseded

## Date
YYYY-MM-DD

## Context
What is the problem or situation that requires a decision?

Include:
- business drivers
- constraints
- technical considerations
- risks

## Decision
What has been decided?

Be explicit and unambiguous.

## Alternatives Considered

### Option 1: <Name>
- Description
- Pros
- Cons

### Option 2: <Name>
- Description
- Pros
- Cons

## Consequences

### Positive
- <Benefit>

### Negative
- <Trade-off>

### Neutral / Risks
- <Risk>

- Business
- Solution
- Data
- Security
- Infra
- Agents
