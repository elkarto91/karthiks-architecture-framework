## 3. Example

- Become a top 3 institutional stablecoin payment provider

- Enable compliant cross-border payments
- Reduce settlement time to <5 seconds

| Metric | Target |
|--------|--------|
| Latency | < 5 sec |
| Uptime | 99.9% |

## 4. Guidance

- Goals must be measurable
- KPIs must map to architecture decisions
- Avoid vague statements like "improve performance"
