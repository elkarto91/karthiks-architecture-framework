# Service Catalog Template Guide

## 1. Purpose
Defines the services/modules in the solution and their contracts at a summary level.

## 2. Template

| Service / Module | Type | Responsibility | Inputs | Outputs | Owner |
|------------------|------|----------------|--------|---------|-------|
|                  |      |                |        |         |       |

## 3. Example

| Service / Module | Type | Responsibility | Inputs | Outputs | Owner |
|------------------|------|----------------|--------|---------|-------|
| Payment API | API | Accept payment requests | Payment request | Payment response | Platform Team |
| Compliance Engine | Internal Service | Validate policy and sanctions | User/payment data | Compliance verdict | Risk Team |

## 4. Guidance
- Good for portfolio-level mapping
- Keep concise
- Use consistent naming across projects
